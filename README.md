Challenge #1: Revising the Select Query
Date: 2026-10-27

Source: HackerRank

Difficulty: Easy

Topic: SELECT, WHERE

Challenge Link:
https://www.hackerrank.com/challenges/revising-the-select-query/problem

Problem Statement:
Retrieve all columns for all American cities in the CITY table with populations larger than 100000.

Solution
SELECT *
FROM CITY
WHERE COUNTRYCODE = 'USA'
AND POPULATION > 100000;
Key Concepts Learned
SELECT * returns all columns.
WHERE filters records.
Multiple conditions can be combined using AND.
